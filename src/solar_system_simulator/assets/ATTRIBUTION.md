# NASA insignia

The unmodified NASA insignia in `nasa-logo.svg` is credited to NASA.

Source: https://www.nasa.gov/wp-content/themes/nasa/assets/images/nasa-logo.svg

It identifies NASA/JPL Horizons beside the initial-data loading controls. It is
not the app's branding and does not indicate NASA endorsement. The NASA insignia
is not covered by the application's MIT license or the planet maps' CC BY license.

NASA brand information: https://www.nasa.gov/nasa-brand-center/

# Application icon

The Antikythera-inspired solar-system icon was generated for this application
using the built-in image generation tool. The original transparent image is
`app-icon.png`; `app-icon.ico` and `app-icon.icns` are resized format conversions.
The complete generation prompt and method are recorded in `app-icon.json`.
